# Linux Basics

Welcome to the **Linux Basics** section of my Linux for DevOps repository.

This section covers the fundamental Linux commands that every DevOps Engineer should know before working with cloud platforms, automation tools, Docker, Kubernetes, and CI/CD pipelines.

## 📚 Topics Covered

- pwd
- ls
- cd
- mkdir
- touch

## 🎯 Goal

Build a strong foundation in Linux navigation and filesystem management.

## 📂 Files

| Command | Description |
|----------|-------------|
| pwd | Print Working Directory |
| ls | List files and directories |
| cd | Change Directory |
| mkdir | Create directories |
| touch | Create empty files |
